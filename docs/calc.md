# 🧮 计算器模块（calc）

[← 返回 README](../README.md)

算式求值 + 中文读法 + 会计大写 + 连续计算，纯 Python 标准库实现（AST 白名单求值，
不使用 `eval`），核心在 `modules/calc/engine.py`，不依赖框架，可独立跑自测。

---

## 基础用法

直接把算式发给 bot：

```text
66*9/8        → 66*9/8 = 74.25
1,500+1       → 千分位、小数都认
(50+50)人民币  → 算式后接货币名 = 直接换算成人民币
1+1mj         → 算式后接拼音 = 直接换算成美元
```

支持的运算符：`+ - * / ^（幂） %（取余） //（整除）`，支持任意层级括号。

## 结果显示

三种格式在 `/calc` 设置面板切换：

| 格式 | 示例输出 |
|---|---|
| 仅结果 | `74.25` |
| 算式+结果 | `66*9/8=74.25` |
| 算式+结果（结果） | `66*9/8=(74.25)` —— 结果可点击复制 |

## 中文读法 / 会计大写

结果下方可附带两种中文读法（设置面板独立开关，可全开/全关/单开）：

```text
自然读法：七十四点二五
会计大写：柒拾肆元贰角伍分      ← 金额场景自动按「元角分」读
```

## 连续计算

上次结果可以直接接续运算，不用重打整条算式：

```text
44             → 44（裸数字静默记录，不打扰）
+56            → 44+56 = 100
*2             → 100*2 = 200
/00            → 手动退出连续计算
/11            → 重新开启连续计算
```

- 连续计算支持 `+ - * / ^ % //` 全部运算符；
- 上次结果 **3 分钟内有效**，超时自动退出（静默，不弹提示）；
- 裸数字（`44`、`1,500`、`3.14`）输入**不回复**，只静默记录，等后续接运算符；
- 与汇率模块联动：裸数字/算式记录后，直接发 `usd`、`大饼` 等币种即按上次结果换算。

## 与汇率模块联动

连续计算的特性让「算完就换算」变成一步：

```text
66*9/8         → 74.25（算式）
mj             → 74.25 美元 ≈ 人民币/港币/日元 …
0.5btc         → 0.5 比特币 ≈ …
大饼           → 黑话也认识
```

## 设置面板（/calc）

| 设置 | 说明 |
|---|---|
| 小数位保留 | 1~6 位，默认 2 位 |
| 结果显示格式 | 「算式+结果」和「（结果）」两个独立开关：只开前者=算式+结果，两个全开=算式+（结果），全关=仅结果 |
| 结果转换 | 「自然读法」「会计大写」独立开关，两个全开=两种都显示 |
| 连续计算 | 开关；面板常驻显示 `/11 开启 · /00 退出` 提示 |

## 命令一览

| 命令 | 作用 |
|---|---|
| `/calc` | 打开设置面板 |
| `/00` | 退出连续计算 |
| `/11` | 开启连续计算 |
| `ans` | 查看上一次结果（连续计算开启时） |

## 安全与实现

- 求值基于 Python `ast` 模块 + 白名单节点，**不使用 `eval`**；
- 表达式节点数上限（防构造超长表达式拖垮进程）；
- 分数运算（`Fraction`）保证精度，不丢小数位；
- IPv4 形如 `1.2.3.0/24`、纯英文单词不会被误当算式。

# 🌐 IP 归属查询模块（ip）

[← 返回 README](../README.md)

发一个 IP 地址，立刻返回归属详情：国家地区、运营商、ASN、机房/代理标记、时区、坐标。
免费免登录（主源 ip-api.com 中文返回，备源 ipwho.is 自动降级），核心在
`modules/ip/engine.py`，不依赖框架，可独立跑自测。

## 用法

```text
179.255.112.32      → 直接发 IP，出归属报告
1.2.3.4:8080        → 带端口也认（自动剥掉端口）
2001:db8::1         → IPv6 支持
/ip                 → 用法提示
```

只有**整条消息就是一个 IP** 才触发——句子中顺带提到 IP 不会误伤。

## 输出示例

```text
🌐 179.255.112.32
🇧🇷 巴西 · 圣保罗州 · 圣保罗 · 邮编 01310
────────────
📡 运营商：Vivo
🏷 ASN：AS28573 Claro NET
⚠️ 属性：机房数据中心
🕐 时区：America/Sao_Paulo
📍 坐标：-23.55, -46.63
────────────
ip-api.com
```

消息下方按钮：

| 按钮 | 作用 |
|---|---|
| 🗺 打开地图 | 按坐标跳 Google Maps |
| 🔄 重新查询 | 强制重新拉取（绕过缓存） |

## 数据源

| 源 | 角色 | 特点 |
|---|---|---|
| ip-api.com | 主源 | 中文返回、字段最全、含代理/机房/移动标记（45 次/分） |
| ipwho.is | 备源 | 主源失败/超时自动降级（HTTPS） |

- 同 IP 结果缓存 **10 分钟**（防重复查询浪费免费配额）；
- 保留地址（192.168.x.x、127.x 等）直接明确提示，不会拿去打外部源；
- 两个源都失败时给出明确报错。

## 启用

```bash
# data/modules.json 的 enabled 里加 "ip"
sudo systemctl restart unmi_TGtool
```

或用 `/modules` 面板启用。

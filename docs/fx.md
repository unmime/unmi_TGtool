# 💱 汇率换算模块（fx）

[← 返回 README](../README.md)

法币 + 加密货币汇率换算。中文名、英文名、ISO 代码、拼音、黑话、emoji 全认识，
直接发就出结果。核心在 `modules/fx/engine.py`，不依赖框架，可独立跑自测。

---

## 基础用法

```text
22人民币        → 22 人民币 ≈ 美元/欧元/…（按展示货币列表）
100usd         → 100 美元 ≈ 多币种
$100           → 符号也认识
100usd cny     → 指定目标：100 美元 ≈ 人民币
1mjrbxjpcny    → 链式：美元→人民币→日元→加元 一条发完
```

能识别的写法：中文名（人民币/美元/日元…）、英文常用名（US Dollar）、ISO 代码
（USD/CNY）、拼音缩写（mj/meigy/rb）、符号（$ ￥ £ €）、 emoji 旗帜、
黑话（大饼=比特币、二饼=以太坊、U=泰达…）、错别字模糊匹配。

### 加密换算开关

默认开启。`/fx` 菜单可关——关闭后所有加密币种从结果里消失，当作纯法币计算器。
关着时发加密相关的消息，bot 会给一个**一键开启**按钮，点了立刻恢复并出结果。

## 展示货币（法币 / 加密分开管理）

换算结果默认按你的「展示货币列表」输出，法币和加密是**两张独立的单子**：

- 输入法币（`100usd`）→ 只显示法币单里的币种；
- 输入加密（`0.5btc`）→ 只显示加密单里的币种。

菜单 `/fx` 管理：

| 按钮 | 作用 |
|---|---|
| ➕️ 添加法定货币 / ➕️ 添加加密货币 | 向导：直接打字（`人民币 美元` / `大饼 二饼`），认出来的自动勾选 |
| 🔄 重置法定货币 / 🪙 重置加密货币 | 分别清空两张单子 |
| 🪙 加密货币换算：开/关 | 加密总开关 |

向导支持**连续添加**：一次输入一批，之后继续发消息接着加，点「✔ 完成」结束；
顺序保持你输入的顺序；写错字有模糊匹配提示，没认出来的会明确告知。

## 与计算器联动

依赖计算器模块（默认启用，建议保持）：

```text
66*9/8         → 74.25
mj             → 74.25 美元 ≈ 多币种
0.5btc         → 0.5 比特币 ≈ 多币种
```

- 任何算式结果之后，**直接发币种名**即按该结果换算；
- 反过来，`66*9/8mj` 一条消息也算（算式+币种连写）；
- 计算器模块被停用时汇率换算依然正常，仅失去联动能力。

## 缓存与降级

- 法币汇率缓存 1 小时、加密 5 分钟，全部落盘，重启不丢；
- 主源拉取失败自动尝试下一个源；
- 网络完全不可用时使用最后一份成功缓存（带时间戳提示数据可能过期）。
